# Corpus académico sintético completo

Abra index.html en un navegador después de extraer el ZIP. No requiere servidor, JavaScript ni conexión a Internet. Mantenga las carpetas para conservar enlaces y estilos.

Contiene 250 documentos informativos, diez por cada una de las 25 facultades, más 25 índices de facultad y un índice principal. Todos utilizan styles.css en la raíz.

Los documentos son sintéticos y de uso académico en Recuperación de Información. No constituyen información institucional oficial, programas de estudio, requisitos ni asesoría profesional. Los casos son hipotéticos.

Nombres de facultades: https://www.buap.mx/content/unidades-acad%C3%A9micas
Fecha de consulta: 12 de noviembre de 2026. Las denominaciones de área siguen las instrucciones del solicitante; su uso es editorial, sin afirmar una adscripción institucional verificada.
